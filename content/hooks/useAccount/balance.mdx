# Read Balances

Use `currentProvider` from `useAccount()` to read the connected wallet's native token balance. Balance requests use the active chain, so request a fresh balance after changing accounts or networks.

## EVM

```tsx
import { useAccount } from "@dogeos/dogeos-sdk";

export function EvmBalanceButton() {
  const { address, chainType, currentProvider } = useAccount();

  async function readBalance() {
    if (!address || chainType !== "evm" || !currentProvider) return;
    try {
      const balanceHex = await currentProvider.request({
        method: "eth_getBalance",
        params: [address, "latest"],
      });
      console.log("Balance in base units:", BigInt(balanceHex));
    } catch (error) {
      console.error("Could not read balance:", error);
    }
  }

  return (
    <button disabled={!address || chainType !== "evm" || !currentProvider} onClick={readBalance}>
      Read EVM balance
    </button>
  );
}
```

The result is a hexadecimal quantity in the chain's smallest unit. DogeOS Chikyū uses 18 decimal places for DOGE. Use a bigint-aware formatter when converting the result for display.

## Dogecoin

The Dogecoin provider's `getBalance()` returns `confirmed`, `unconfirmed`, and `total` amounts in satoshis. One DOGE is 100,000,000 satoshis.

```tsx
import { useAccount } from "@dogeos/dogeos-sdk";

export function DogecoinBalanceButton() {
  const { address, chainType, currentProvider } = useAccount();
  const canReadBalance = Boolean(address) && chainType === "dogecoin" &&
    currentProvider != null && typeof currentProvider.getBalance === "function";

  async function readBalance() {
    if (!canReadBalance || !currentProvider) return;
    try {
      const balance = await currentProvider.getBalance();
      console.log("Total balance in satoshis:", balance.total);
    } catch (error) {
      console.error("Could not read balance:", error);
    }
  }

  return <button disabled={!canReadBalance} onClick={readBalance}>Read Dogecoin balance</button>;
}
```
