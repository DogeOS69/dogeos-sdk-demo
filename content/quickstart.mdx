# Quick Start

## Overview

Get started with DogeOS SDK in minutes. This guide will walk you through the basic setup and usage.

## Installation

```bash
npm install @dogeos/dogeos-sdk@4.0.1
```

## Basic Setup

### 1. Wrap your app with WalletConnectProvider

```tsx
import { WalletConnectProvider } from "@dogeos/dogeos-sdk";

export default function App() {
  return (
    <WalletConnectProvider
      config={{
        clientId: "your-client-id",
      }}
    >
      <YourApp />
    </WalletConnectProvider>
  );
}
```

**Note:** `clientId` is required for embedded wallet functionality. Get your client ID from [DogeOS](https://sdk.dogeos.com/).

SDK 4.0.1 prefers the injected MyDoge wallet inside the native app and does not initialize an embedded-wallet iframe in that path. Keep your normal browser login configuration: email and social login remain available outside the native app. See [native routing](/provider-config#native-mydoge-routing).

### 2. Use the hooks

The SDK provides two main hooks:

- `useWalletConnect()` - For modal control and connection state
- `useAccount()` - For account info and actions

## Key Concepts

- **Provider**: Wrap your app with `WalletConnectProvider` to enable wallet functionality
- **Hooks**: Use `useWalletConnect` and `useAccount` to interact with wallets
- **Modal**: The SDK provides a built-in wallet selection modal
- **Connection State**: Track wallet connection status with `isConnected`; it does not establish an authenticated app session.
- **Embedded Readiness**: `walletStatus` and `isWalletReady` describe embedded custody, not an injected wallet. Do not gate native signing on them.

## Next Steps

- Explore the `useWalletConnect` hook for connection management
- Explore the `useAccount` hook for account information and signing
- Check out the Provider documentation for chain-specific operations

## Complete Example

```tsx
import React from "react";
import {
  WalletConnectProvider,
  useWalletConnect,
  useAccount,
} from "@dogeos/dogeos-sdk";

function WalletDemo() {
  const { openModal, isConnected, disconnect } = useWalletConnect();
  const { address, chainId, signMessage, signInWithWallet } = useAccount();

  return (
    <div>
      {isConnected ? (
        <div>
          <div>Address: {address}</div>
          <div>Chain ID: {chainId}</div>
          <button onClick={() => signMessage?.({ message: "Hello" })}>
            Sign Message
          </button>
          <button onClick={disconnect}>Disconnect</button>
        </div>
      ) : (
        <button onClick={openModal}>Connect Wallet</button>
      )}
    </div>
  );
}

export default function App() {
  return (
    <WalletConnectProvider
      config={{
        clientId: "your-client-id",
      }}
    >
      <WalletDemo />
    </WalletConnectProvider>
  );
}
```

**Note:** Get your client ID from [DogeOS](https://sdk.dogeos.com/).

## Connect Button Example

```tsx
import { useWalletConnect } from "@dogeos/dogeos-sdk";

export function ConnectButton() {
  const { openModal, isConnected, disconnect } = useWalletConnect();

  return (
    <button onClick={() => (isConnected ? disconnect() : openModal())}>
      {isConnected ? "Disconnect" : "Connect Wallet"}
    </button>
  );
}
```

## Account Info and Signing Example

```tsx
import { useAccount } from "@dogeos/dogeos-sdk";

export function AccountInfo() {
  const { address, chainId, signMessage, signInWithWallet } = useAccount();

  const onSignMessage = async () => {
    const sig = await signMessage?.({ message: "Hello DogeOS" });
    console.log("signature:", sig);
  };

  const onSignin = async () => {
    const signature = await signInWithWallet();
    console.log("Demo signature (no session):", signature);
  };

  return (
    <div>
      <div>Address: {address}</div>
      <div>ChainId: {chainId}</div>
      <button onClick={onSignMessage}>Sign Message</button>
      <button onClick={onSignin}>Sign Demo Challenge</button>
    </div>
  );
}
```

`signInWithWallet` returns a signature, not an authentication token. For production authentication, use a one-use server challenge and backend verification as described in [signInWithWallet](/hooks/useAccount/signInWithWallet).
